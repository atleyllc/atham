# ATHAM visual tokens

Field instrument. Flat color. No brushed metal, screws, or heavy gradients.

| Token | Value | Use |
| --- | --- | --- |
| Black | `#0C0D0B` | Screen background |
| Graphite | `#181A17` | Bars and panels |
| Graphite raised | `#22241F` | Secondary controls |
| Line | `#34362F` | Hairline dividers |
| Gold | `#C4A46A` | Callsign, active destination, UNKEY, PTT outline |
| Gold dim | `#8A7044` | Roadmap status |
| Text | `#F3F0E8` | Primary reading |
| Muted | `#9A968C` | Secondary reading |
| Receive | `#8FAF7A` | Open squelch and observing |
| Transmit | `#E0B15A` | Keyed state |
| Error | `#C46B5A` | Disconnect and blocked PTT |

Minimum touch target: 48 px. UNKEY and PTT are larger.

Portrait chrome is a top identity bar and four bottom destinations: Home, Radio, Log, Modules. Landscape keeps the same identity, frequency, UNKEY, and destinations, with PTT on the right.
